Key Features

Nesting and Uniformity

Allows structuring code in a hierarchy. Uniformity ensures every block has the same predictable shape, making code easy to sort and comprehend.

Unified Clear Syntax

Consistent and strict syntax rules. No hidden magic, making the codebase transparent and easy to read for any developer.

Language Integration

Seamlessly integrates with any language. You can declare a table as native, and its execution logic will be pulled from another language.
